# Clean Home Essentials

Crie um site completo, moderno, responsivo e profissional para uma loja online especializada em produtos têxteis para limpeza e uso doméstico.

A loja vende produtos como:

- Panos de microfibra

- Panos de prato

- Panos de chão

- Saco alvejado

- Panos de pia

- Panos lisos

- Panos xadrez/quadriculados

- Kits para limpeza

- Outros produtos têxteis domésticos

OBJETIVO DO SITE

O objetivo principal é VENDER.

O site não deve parecer apenas um catálogo institucional. Ele deve funcionar como uma pequena loja virtual, permitindo que o cliente:

1. Navegue pelos produtos

2. Pesquise produtos

3. Filtre por categoria

4. Veja fotos e informações detalhadas

5. Escolha variações

6. Escolha quantidade

7. Adicione produtos ao carrinho

8. Visualize subtotal e total

9. Finalize o pedido pelo WhatsApp

A estrutura deve ser preparada para futuramente receber checkout e pagamento online.

--------------------------------------------------

IDENTIDADE VISUAL

--------------------------------------------------

Criar uma identidade visual relacionada ao segmento de limpeza e produtos têxteis.

Estilo:

- moderno

- profissional

- limpo

- confiável

- comercial

- visual de e-commerce

- sem aparência infantil

- sem excesso de elementos

Utilizar bastante espaço em branco.

Paleta principal:

- azul-marinho

- branco

- detalhes em laranja

Usar tipografia moderna e muito legível.

Não exagerar em gradientes, sombras ou animações.

O produto deve ser sempre o protagonista.

IMPORTANTE:

Caso sejam fornecidos posteriormente logotipo, cores oficiais e imagens reais dos produtos, preservar exatamente esses materiais, sem redesenhar logotipo ou modificar características dos produtos.

RESPONSIVIDADE

--------------------------------------------------

O site deve funcionar perfeitamente em:

- celular

- tablet

- notebook

- desktop

Priorizar MOBILE FIRST, pois grande parte das compras acontecerá pelo celular.

No celular:

- cards bem dimensionados

- botões grandes

- carrinho fácil de acessar

- botão de WhatsApp acessível

- nenhuma rolagem horizontal

- textos legíveis

ESTRUTURA TÉCNICA

--------------------------------------------------

Criar código organizado e fácil de manter.

Separar:

- componentes

- dados dos produtos

- funções do carrinho

- configuração da loja

- estilos

Não espalhar preços, telefone ou dados da empresa diretamente pelo código.

Criar configurações centralizadas para:

NOME_LOJA

WHATSAPP

INSTAGRAM

EMAIL

ENDERECO

CORES

FRETE

PRODUTOS

Os produtos devem ser fáceis de adicionar, remover ou editar.

- banco de dados

- painel administrativo

- cálculo de frete por CEP

- Mercado Pago

- Pix

- cartão

- integração com WhatsApp

- integração com marketplaces

REGRA MAIS IMPORTANTE

--------------------------------------------------

Não invente informações comerciais.

Quando algum dado estiver faltando, utilize claramente um placeholder editável, como:

[WHATSAPP]

[INSTAGRAM]

[NOME DA LOJA]

[EMAIL]

Não invente:

- medidas

- composição

- estoque

- avaliações

- descontos

- certificações

- prazo de entrega

- frete grátis

Quero um site com aparência de E-COMMERCE REAL, comercial e confiável, e não uma landing page genérica.

Comece apresentando a estrutura visual e de páginas. Depois implemente o site.
